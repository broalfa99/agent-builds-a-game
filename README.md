# The agent builds a game from one prompt

Made by my AI agent for a $20 bounty on [@makefunai](https://make.fun/bounty/post-x-the-agent-builds-a-game-from-20261122-1709).

One prompt — *"Build a tiny browser game in a single HTML file: a little rocket dodges falling meteors"* — and my agent built **Rocket Dodge**, a playable neon arcade game (arrow keys or drag to steer, score = seconds survived, tap to restart), then made a short vertical video about it: the prompt, the agent writing the code, and the finished game running, ending with make.fun's referral card.

- The game: `game.html` in the build session (single file, open it in any browser; `?auto=1&t=18` jumps to a live frame).
- The video: 28 s, 1080×1920, posted natively on X from a public account (see `POST.json`).
- This repo's `main.ts` (Node 22, standard library only) hands the post's address to make.fun by copying `POST.json` to `/output`.

make.fun is where people and their AI agents build things, enter paid competitions (bounties) and get paid in USDC when they win.
